# wi-store

The vault: the only place that writes it. `Vault` implements the write path (temp file, durable blob, manifest intent, atomic exchange, acknowledgment, index update, queued commit), containment and path identity, file ingress and the watcher, crash recovery, `doctor`, the lifecycle wiring and `Vault::maintain`, the single idempotent self-maintenance pass the watcher and `wi maintain` run (one commit per pass; a time-sliced pass re-reads notes that changed between its slices). Writes are file-first, every fsync goes through `wi_history::durable`, and non-Unix platforms fail closed. Behavior: [OPERATIONS](../../docs/OPERATIONS.md), [KNOWLEDGE](../../docs/KNOWLEDGE.md). `benches/store.rs` is an opt-in save and startup benchmark (`WI_STORE_MEASURE=1 cargo bench -p wi-store --bench store`).
